## How to Install (Takes ~30 Seconds)

Until Confession Hover is listed on the Chrome Web Store, you can install it directly in any Chromium-based browser:

1. **Download & Unzip**  
   Click **[Download Latest Extension (.zip)](https://github.com/Aussie-App-Studio/Confession-Hover/releases/latest/download/Confession-Hover.zip)** above, then extract the `.zip` file into a folder you'll keep (e.g., `Documents/Confession-Hover`).
2. **Open Your Browser's Extensions Page**  
   - **Chrome:** `chrome://extensions`
   - **Edge:** `edge://extensions`
   - **Brave:** `brave://extensions`  
   Turn on **Developer mode** using the toggle in the top-right corner.
3. **Load the Extension**  
   Click **Load unpacked** (top-left) and select the extracted `Confession-Hover` folder — or simply drag and drop the folder onto the extensions page.

That's it! Click the puzzle-piece icon in your toolbar to pin **Confession Hover**.

## What's Included

### ⚡ 8 Standards Built-In (Works 100% Offline)
Hover over references like *WCF 1.2*, *Heidelberg Catechism Q. 26*, *Lord's Day 12*, *Belgic Confession Art. 33*, *Canons of Dort 3/4.3*, or *2LBCF 26.1* anywhere on the web to read them instantly:

- **Heidelberg Catechism (1563)** — all 129 Q&As + all 52 Lord's Days
- **Belgic Confession (1561)** — all 37 Articles
- **Canons of Dort (1619)** — Heads 1–5, including Rejection of Errors
- **Westminster Confession of Faith (1647)** — all 33 Chapters
- **Westminster Larger Catechism (1647)** — all 196 Q&As
- **Westminster Shorter Catechism (1647)** — all 107 Q&As
- **1689 London Baptist Confession** — all 32 Chapters
- **CRCA Book of Order (2022)** — all 86 Articles

### 🧩 1-Click Extra Creeds & Custom Packs
Inside the extension's Dashboard, you can add 14+ more historic documents in one click (Apostles' Creed, Nicene Creed, Athanasian Creed, Chalcedonian Definition, Scots Confession, Second Helvetic Confession, Keach's Catechism, Spurgeon's Puritan Catechism, and more) or import your own `.json` packs.

### 🎨 Clean, Customizable Reading Experience
- **Full-Chapter Reader Drawer:** Click any preview to read the entire chapter, Lord's Day, or Head of Doctrine without leaving the page.
- **Themes & Typography:** Auto, Crisp Light, OLED Dark, and Warm Sepia themes, plus 6 fonts (including Dyslexia-Friendly) and customizable underline styles.
- **Smart Reference Detection:** Recognizes short citations like `BC 33` or `LD 12` in theological contexts while ignoring false positives like `500 BC` or `.NET WCF`.
- **Coexists with Bible Hover:** Uses a distinct burgundy accent by default so confessional links stand apart from Bible verse links.
