📘 Shareable Community Pack JSON Format Guide

Anyone can create and share a Confession Hover pack as a single .json file:

{
  "id": "my_confession",
  "name": "My Modern Confession",
  "shortName": "MMC",
  "year": "2024",
  "aliases": ["My Modern Confession", "MMC"],
  "structure": "chapter_section",
  "chapters": { "1": "Of Holy Scripture" },
  "entries": {
    "1.1": "Holy Scripture is the supreme standard...",
    "1.2": "The whole counsel of God..."
  }
}

Supported structure values: "chapter_section" ("1.2"), "catechism" ("26" with {"question":"...","answer":"..."} or plain text), "article" ("33"), "dort" ("1.A7", "1.R3"), and "creed" ("1").
